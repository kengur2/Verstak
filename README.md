# Verstak

[![Проверка](https://github.com/kengur2/Verstak/actions/workflows/ci.yml/badge.svg)](https://github.com/kengur2/Verstak/actions/workflows/ci.yml)

Единая программа для работы с [OpenCode](https://opencode.ai): проекты, сессии,
задачи по расписанию, файлы, статистика, подключение с телефона и приложение для
Android.

Интерфейс полностью на русском языке.

## Что внутри

| Часть | Назначение |
| --- | --- |
| `packages/server` | Локальный HTTP-сервер: вход, проксирование к OpenCode, задачи по расписанию, сопряжение телефона |
| `packages/web` | Интерфейс (React + Vite), одна сборка для десктопа и телефона, устанавливается как PWA |
| `packages/mobile` | Мобильное приложение для Android (Capacitor) — оболочка вокруг той же веб-сборки |

Сервер не тянет внешних фреймворков: только `node:http`, `ws` и `yaml`.
Веб-интерфейс — React 19 и Vite.

## Требования

- Node.js 22 или новее
- Установленный OpenCode (`~/.opencode/bin/opencode`) — с запущенной службой

## Быстрый старт

```bash
npm install
npm run build
npm start
```

Интерфейс откроется на <http://127.0.0.1:57311>. При первом запуске программа
предложит задать пароль для входа — сам пароль не хранится, сохраняется только
scrypt-хеш.

## Экран сессии

- **Список сессий** — последние сессии выбранного проекта с относительным
  временем и объёмом вывода.
- **Лента** — реплики пользователя справа, ответы ассистента слева; блоки кода,
  `код` в строке, **жирный**, *курсив* и ссылки распознаются.
- **Вызовы инструментов** — отдельными строками с именем и состоянием.
- **Выбор модели** — с поиском по названию и провайдеру: у OpenCode бывают
  сотни моделей, обычный список был бы неудобен.
- **Поток событий** — лента обновляется сама, кнопка «Остановить» прерывает
  генерацию.

## Оформление

Тема выбирается в «Настройках» и переключается кнопкой в шапке боковой панели:

- **Светлая**
- **Тёмная**
- **Как в системе** — следит за настройкой ОС и меняется без перезагрузки

Выбор сохраняется в браузере. Тема применяется до первой отрисовки, поэтому
страница не мигает светлым при загрузке в тёмной теме.

## Язык

Русский — язык по умолчанию, английский доступен в настройках. Словари лежат в
`packages/web/src/i18n/messages.ts`; ключи выводятся из русского словаря, поэтому
пропущенный перевод обнаруживается при проверке типов.

## Подключение с телефона

Есть два способа.

**Браузер на телефоне (PWA).** Проще всего: ничего устанавливать не нужно.

1. Включите «Доступ из локальной сети» в настройках (по умолчанию выключен —
   сервер слушает только `127.0.0.1`) и перезапустите сервер.
2. Откройте «Устройства» и создайте код сопряжения. Код одноразовый, живёт
   10 минут.
3. Откройте адрес сервера на телефоне в той же сети и введите код.
4. Телефон получит постоянный токен; страницу можно добавить на главный экран
   как приложение.

**Приложение для Android.** Отдельная сборка: интерфейс тот же, но адрес
сервера вводится один раз при первом запуске, а код можно не вводить руками —
достаточно навести камеру на QR-код с экрана компьютера.

```bash
npm run mobile:apk
adb install -r packages/mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

Подробности — в [docs/mobile.md](docs/mobile.md).

Отозвать доступ устройству можно на компьютере, в «Устройствах».

## Доступ к файлам проектов

Файлы проекта можно забрать с телефона двумя способами.

**Через приложение.** Раздел «Файлы»: выбираете проект, ходите по папкам,
смотрите небольшие текстовые файлы и скачиваете нужное. В приложении файл
сохраняется в папку «Документы»; если система не разрешает запись, открывается
окно «Поделиться», откуда файл можно отправить куда угодно.

**По SFTP.** В «Настройках» включите «Доступ по SFTP» — файлы проектов станут
доступны любому файловому менеджеру на телефоне. Адрес, пользователь и
отпечаток ключа показаны в разделе «Устройства».

```
sftp://192.168.1.5:57312
Пользователь: verstak
Пароль: как для входа в Verstak (или токен устройства)
```

Что важно знать про SFTP:

- видно только папки проектов, выйти за их пределы нельзя;
- по умолчанию доступен только просмотр и скачивание; запись включается
  отдельной настройкой;
- аутентификация та же, что у входа в программу.

## Статистика использования

Раздел «Статистика» показывает, сколько израсходовано: сессии, токены и
стоимость за выбранный период — сутки, 7 дней, 30 дней или всё время.

Разрезы: по проектам, по моделям и по дням (столбиками). Токены разбиты на
вход, выход и рассуждения, отдельно показано чтение из кэша.

Данные не собираются специально: их уже хранит OpenCode по каждой сессии,
поэтому история начинается не с момента установки Verstak, а с самих
сессий. Считаются последние 500 сессий каждого проекта.

## Задачи по расписанию

Задача запускает промпт в выбранной папке по расписанию: каждые N минут,
ежедневно, по дням недели или один раз в указанное время. Задачу можно
запустить вручную, приостановить и удалить.

| Что | Где |
| --- | --- |
| Настройки | `~/.config/verstak/config.yaml` |
| Хеш пароля | `~/.config/verstak/auth.yaml` |

## Разработка

```bash
npm run dev          # сервер + интерфейс с горячей перезагрузкой
npm run build        # сборка обоих пакетов
npm run typecheck    # проверка типов
```

### Что не хранится в репозитории

В репозитории только исходники: около 116 файлов и меньше мегабайта. Всё
остальное создаётся командами и в git не попадает:

| Что | Как получить |
| --- | --- |
| `node_modules` | `npm install` |
| `packages/web/dist` | `npm run build:web` |
| `packages/mobile/dist` и файлы приложения внутри Android-проекта | `npm run mobile:sync` |
| APK | `npm run mobile:apk` |
| Ключи подписи (`*.jks`, `*.keystore`) | создаются вами, в репозиторий не попадают |

Подробнее об устройстве интерфейса — в [docs/interface.md](docs/interface.md).
