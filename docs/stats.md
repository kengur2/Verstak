# Статистика использования

Раздел «Статистика» отвечает на вопрос «сколько израсходовано»: сессии, токены
и стоимость за выбранный период, в разрезе проектов, моделей и дней.

## Откуда берутся данные

Специального сбора нет. OpenCode хранит по каждой сессии:

| Поле | Что это |
| --- | --- |
| `cost` | Стоимость сессии |
| `tokens.input` | Токены запроса |
| `tokens.output` | Токены ответа |
| `tokens.reasoning` | Токены рассуждений |
| `tokens.cache.read` / `write` | Работа с кэшем |
| `model` | Провайдер и модель |
| `time.created` | Когда сессия создана |

Verstak обходит известные проекты, забирает их сессии и складывает.
История поэтому начинается не с установки программы, а с самих сессий — те
сессии, что были раньше, тоже попадут в сводку.

Важно: сумма по проектам не равна сумме «вообще», потому что один и тот же
проект может открываться разными путями. Дубли не вычитаются.

## Как считается

`packages/server/src/stats.ts`:

1. Берётся список недавних проектов (`recentFolders`) — те же, что видны в
   интерфейсе.
2. По каждому проекту запрашиваются сессии: `GET /api/session?limit=500&directory=…`
   у самого OpenCode, с сужением по папке проекта.
3. Сессии отсеиваются по времени (`days`), затем складываются в четыре набора:
   итог, по проектам, по моделям и по дням.

День определяется по местной дате (`2026-10-01`), а не по UTC: так столбики
совпадают с календарём пользователя.

Ответ кэшируется на 20 секунд. Кэш сбрасывается, когда в программе появляется
новый проект: иначе сводка не увидела бы новые сессии.

## Ограничения

- **Окно — 500 сессий на проект.** Это верхняя граница запроса к OpenCode. Если
  сессий больше, в сводку попадут последние.
- **Стоимость зависит от провайдера.** Для локальных моделей (например,
  `opencode/big-pickle`) она нулевая — это нормально, платить не за что.
- **Недоступный проект не ломает сводку.** Если OpenCode не ответил, проект
  пропускается, а причина показывается в интерфейсе отдельной строкой.
- **Проекты без сессий в окне не показываются** — иначе список был бы забит
  пустыми строками.

## API

```
GET /api/stats?days=7
```

`days` — размер окна в днях; `0` или отсутствие значения означает «всё время».
Ответ:

```json
{
  "generatedAt": 1790877200000,
  "days": 7,
  "totals":    { "key": "totals", "sessions": 3, "cost": 0.61, "tokens": { "…": 0 } },
  "projects":  [ { "key": "/путь", "directory": "/путь", "sessions": 3, "…": 0 } ],
  "models":    [ { "key": "deepseek/deepseek-flash", "sessions": 1, "…": 0 } ],
  "byDay":     [ { "key": "2026-10-01", "sessions": 3, "…": 0 } ],
  "errors":    []
}
```

## Интерфейс

- Период переключается сегментами: сутки, 7 дней, 30 дней, всё время.
- Три крупных числа: сессии, токены, стоимость.
- Столбики по дням появляются, когда дней в выборке больше одного.
- Таблицы по проектам и по моделям; нулевая стоимость показывается прочерком.

Столбики нарисованы обычными блоками: высота считается от самого крупного дня
в выборке. Библиотека графиков здесь была бы лишним весом.
