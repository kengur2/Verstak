# Мобильное приложение

Приложение — оболочка [Capacitor](https://capacitorjs.com) вокруг того же веб-интерфейса,
что открывается в браузере. Отдельной сборки интерфейса нет: пакет
`packages/mobile` копирует готовый `packages/web/dist`. Поэтому экраны,
оформление и логика в приложении и в браузере не расходятся.

```
packages/mobile
├── android/                 проект Android (создан Capacitor)
├── dist/                    скопированная веб-сборка (в репозиторий не попадает)
├── scripts/
│   ├── prepare-web-assets.mjs  копирует web/dist
│   └── generate-icons.mjs      рисует иконки и заставку
└── capacitor.config.ts
```

## Чем приложение отличается от браузера

В браузере страницу отдал сервер, поэтому запросы идут относительными путями.
В приложении страница лежит внутри телефона, и адрес сервера нужно знать
отдельно. Отсюда два отличия:

1. **Экран подключения.** При первом запуске приложение просит адрес сервера,
   затем код сопряжения или пароль. Адрес сохраняется, дальше вход не требуется.
2. **Токен вместо cookie.** Cookie в приложении ненадёжна (свой источник,
   возможна блокировка сторонних cookie), поэтому сервер выдаёт постоянный
   токен устройства — тем же способом, что и при сопряжении по коду.

Адрес сервера подставляется ко всем запросам в `lib/server.ts` (`apiUrl`).
Различие сред определяется по объекту `Capacitor`, который добавляет оболочка.

## Подключение телефона

1. На компьютере откройте «Настройки» и включите **«Доступ из локальной сети»**.
   По умолчанию сервер слушает только `127.0.0.1` и с телефона недоступен.
2. Перезапустите сервер: адрес прослушивания выбирается при запуске.
3. В «Устройствах» нажмите «Код сопряжения». Появятся код, QR и адрес для
   телефона. Если сетевых адресов несколько, выберите нужный.
4. В приложении нажмите «Сканировать код» и наведите камеру на QR — адрес и код
   подставятся сами. Либо введите адрес и код вручную.
5. Либо выберите вкладку «Пароль» и войдите логином и паролем сервера.

QR содержит обычную ссылку `http://адрес:порт/?pair=КОД`, поэтому тот же код
открывается и в браузере телефона — приложение для этого не обязательно.

Сменить сервер можно в «Настройках» приложения, там же отзывается доступ
устройства (на компьютере, в «Устройствах»).

## Файлы проектов

В приложении есть раздел «Файлы»: выбор проекта, переход по папкам, просмотр
небольших текстовых файлов и скачивание на телефон.

Скачивание устроено по-разному в зависимости от среды (`lib/download.ts`):

| Среда | Что происходит |
| --- | --- |
| Браузер | Обычное скачивание файла ссылкой |
| Приложение | Запись в папку «Документы»; если система не разрешает — сохранение во внутренний кэш и системное окно «Поделиться» |

Для этого подключены плагины `@capacitor/filesystem` и `@capacitor/share`.
Файл всегда запрашивается с заголовком авторизации: сервер не отдаёт файлы без
входа.

## Доступ по SFTP

Кроме приложения, файлы проектов доступны по SFTP — удобно, если хочется
пользоваться своим файловым менеджером.

- Сервер SFTP встроен в Verstak (`packages/server/src/sftp.ts`) и
  запускается вместе с основным сервером, если включён в настройках.
- В корне видны папки проектов; каждая ведёт на реальную папку на диске.
- Выйти за пределы проектов нельзя: путь нормализуется, а символические ссылки
  разворачиваются и проверяются отдельно.
- По умолчанию доступ только на чтение: телефону файлы нужно скачать, а не
  изменить. Запись включается настройкой `sftpWrite`.
- Аутентификация — имя пользователя и пароль сервера. Вместо пароля принимается
  токен подключённого устройства: он уже есть у телефона.
- Ключ сервера создаётся при первом запуске и лежит в
  `~/.config/verstak/sftp_host_key`. Отпечаток показан в интерфейсе, по
  нему можно убедиться, что подключение идёт к своему компьютеру.

Настройки: `sftpEnabled`, `sftpPort` (по умолчанию 57312), `sftpWrite`. При
изменении порта или доступа сервер перезапускается сразу, без перезапуска
программы.

## Проверка без телефона

Мобильные экраны можно посмотреть в обычном браузере: `?native=1` заставляет
интерфейс считать, что он запущен в приложении.

```
http://127.0.0.1:57311/?native=1
```

Появится экран подключения к серверу — можно ввести адрес и код сопряжения и
пройти весь путь целиком. Этот параметр влияет только на выбор экрана и базового
адреса запросов.

## Русский язык

- Интерфейс: русский — язык по умолчанию, словари в
  `packages/web/src/i18n/messages.ts`.
- Оболочка Android: `android/app/src/main/res/values-ru/strings.xml`.
- Языки приложения объявлены в `res/xml/locales_config.xml`, поэтому в
  настройках Android 13+ русский предлагается первым.

## Разрешения и сеть

| Что | Зачем |
| --- | --- |
| `INTERNET` | Связь с сервером |
| `CAMERA` | Сканирование QR-кода сопряжения (необязательно) |
| `usesCleartextTraffic` | Сервер в локальной сети работает по `http` без сертификата |
| `network_security_config` | Разрешает незашифрованный трафик к серверу |
| `allowMixedContent` | Интерфейс открыт по `https://localhost`, а сервер — по `http` |

CORS на сервере включён: без него браузер внутри приложения запретил бы запросы
к серверу с другого адреса.

## Сборка

```bash
# Из корня проекта
npm run build:web            # свежий интерфейс
npm run mobile:apk           # сборка отладочного APK
```

Готовый файл: `packages/mobile/android/app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый телефон:

```bash
adb install -r packages/mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

### Требования к сборке

- JDK 21 (`JAVA_HOME`)
- Android SDK с платформой 36 и build-tools (`ANDROID_HOME`)
- Gradle скачивается автоматически обёрткой `android/gradlew`

### Подписанная сборка

Отладочный APK подписывается автоматически и годится для установки вручную.
Для публикации нужен свой ключ:

```bash
keytool -genkeypair -v -keystore verstak.jks -alias verstak \
  -keyalg RSA -keysize 2048 -validity 10000

cd packages/mobile/android
./gradlew assembleRelease \
  -Pandroid.injected.signing.store.file=$PWD/verstak.jks \
  -Pandroid.injected.signing.store.password=ПАРОЛЬ \
  -Pandroid.injected.signing.key.alias=verstak \
  -Pandroid.injected.signing.key.password=ПАРОЛЬ
```

## Иконки

`npm run mobile:icons` перерисовывает иконки и заставку во всех плотностях.
Знак повторяет `packages/web/public/icon.svg`, поэтому приложение и интерфейс
выглядят одинаково. Скрипт собирает PNG сам, без внешних инструментов.
